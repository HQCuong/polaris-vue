Polaris web components, typed for Vue

Write Vue. Ship the Shopify admin.

Shopify's Polaris web components (<s-button>, <s-text-field>, <s-modal>, …) work in any framework, but in a Vue template they are untyped custom elements… (đoạn văn hiện tại giữ nguyên)

<script setup lang="ts">
import { ref } from 'vue'
import { SButton, STextField } from 'polaris-vue-elements'
const name = ref('')
</script>

<template>
  <STextField v-model="name" label="Store name" />
  <SButton variant="primary">Save</SButton>
</template>
