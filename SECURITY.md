# Security policy

## Supported versions

Only the latest release of `polaris-vue-elements` receives fixes.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/HQCuong/polaris-vue/security/advisories/new)
with a description, the affected version and steps to reproduce.

You should get a reply within a week. Once a fix is released, the advisory is published with
credit to you unless you'd rather stay anonymous.

Vulnerabilities in the Polaris runtime itself (`cdn.shopify.com/shopifycloud/polaris-*.js`)
belong to Shopify; report those through [Shopify's bug bounty program](https://hackerone.com/shopify).
