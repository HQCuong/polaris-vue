- **색상의 용도를 이름으로 밝히세요.** 일반적인 "Color" 대신 "Button background color"나 "Heading text color" 같은 `label`을 사용합니다.
- **편집할 때는 현재 색상을 보여 주세요.** `value`를 기존 색상으로 설정해 판매자가 무엇에서 바꾸는지 알 수 있게 합니다.

```vue
<SColorField label="Button background color" value="#1a1a1a" />
```

전체 가이드는 [`<s-color-field>`에 대한 Shopify 모범 사례](https://shopify.dev/docs/api/app-home/latest/web-components/forms/color-field#best-practices)(영어)를 참고하세요.
