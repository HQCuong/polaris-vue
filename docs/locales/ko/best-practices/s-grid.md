- **작은 화면을 고려하세요.** 데스크톱에서 잘 동작하는 그리드도 모바일에서는 무너질 수 있습니다. 레이아웃을 하나로 고정하지 말고, 좁은 너비에서 어떻게 재배치할지 결정합니다.
- **일관된 간격 하나를 사용하세요.** 항목 사이의 균일한 간격은 레이아웃에 안정된 리듬을 주고 훑어보기 쉽게 만들므로, 한 그리드 안에서 여러 간격 방식을 섞지 않습니다.
- **넘치는 콘텐츠에 대비하세요.** 셀의 크기는 정해져 있지만 콘텐츠 길이는 다양합니다. 지나치게 길거나 넓은 콘텐츠를 줄바꿈할지, 잘라낼지, 스크롤할지 미리 결정합니다.
- **더 단순한 컴포넌트로 충분하다면 그것을 사용하세요.** `SGrid`는 강력하지만 복잡성을 더하므로, 더 단순한 레이아웃 컴포넌트로 해결되는지 확인하고 그리드는 그 기능이 꼭 필요한 경우에 사용합니다.

전체 가이드는 [`<s-grid>`에 대한 Shopify 모범 사례](https://shopify.dev/docs/api/app-home/latest/web-components/layout-and-structure/grid#best-practices)(영어)를 참고하세요.
