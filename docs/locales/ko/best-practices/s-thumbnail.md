- **가장 좁은 공간에는 `size="small-200"`을 사용하세요.** 공간이 매우 제한된 곳에서만 사용합니다.
- **작은 공간에는 `size="small"`을 사용하세요.** 썸네일을 좁은 영역에 맞춰 넣어야 할 때 사용합니다.
- **기본으로는 `size="base"`를 사용하세요.** 레이아웃에 다른 크기가 필요하지 않다면 여기서 시작합니다.
- **이미지가 중심일 때는 `size="large"`를 사용하세요.** 썸네일이 주목의 중심일 때 사용합니다.
