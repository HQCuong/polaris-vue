- **제자리에서 필터링할 때 사용하세요.** 특정 섹션이나 목록의 콘텐츠를 좁혀 나가는 데 적합합니다. 전역 탐색이나 복잡한 다단계 검색에는 더 강력한 검색 패턴이 필요합니다.
- **무엇을 검색하는지 밝히세요.** 구체적인 `label`과 `placeholder`를 작성해 검색이 어떤 콘텐츠를 대상으로 하고 어떤 속성으로 검색할 수 있는지 판매자에게 알려 줍니다.
- **판매자가 입력하는 동안 반응하세요.** 가능하다면 판매자가 입력하는 동안 결과나 필터링된 콘텐츠를 갱신해, 검색어를 다듬을 수 있고 검색이 동작한다고 믿을 수 있게 합니다.
- **지운 검색과 결과 없는 검색에 대비하세요.** 필드를 지우면 전체 목록을 다시 보여 줍니다. 일치하는 항목이 없으면 다른 액션이나 더 넓은 검색을 제안하는 메시지를 표시합니다.
- **충분한 입력을 기다리세요.** 너무 많거나 의미 없는 결과를 반환할 검색은 실행하지 않습니다. 두세 글자부터 검색을 시작하면 유용한 결과를 돌려주기에 충분합니다.

```vue
<SSearchField label="Search products" placeholder="Search by title, SKU or vendor" />
```
