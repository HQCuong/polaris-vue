- **コンテキストに合わせてサイズを選ぶ。** テーブルやリストのような密度の高いレイアウトでは小さめの `size` を、人物が主役となるプロフィールページでは大きめのものを選びます。
- **役に立つ代替テキストを書く。** `alt` には、人物名や会社名など、アバターが表す人やものを設定します。その名前がすでにアバターの横にテキストとして表示されている場合は、空の `alt` を使います。
- **表す対象のすぐ横に置く。** アバターは、それが表す名前やエンティティのすぐ横に配置し、リスト、テーブル、カードの中でも関係がはっきりわかるようにします。

```vue
<SAvatar alt="Sarah Chen" initials="SC" size="large" />
```

詳しいガイダンスについては、[`<s-avatar>` に関する Shopify のベストプラクティス](https://shopify.dev/docs/api/app-home/latest/web-components/media-and-visuals/avatar#best-practices)（英語）を参照してください。
