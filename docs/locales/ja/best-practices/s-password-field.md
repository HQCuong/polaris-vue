- **パスワードマネージャーと連携させる。** `new-password` や `current-password` など適切な `autocomplete` の値を設定し、パスワードマネージャーがマーチャントの強力なパスワードの生成と保存を手助けできるようにします。
- **ルールは最初に示す。** 無効な入力のあとで明かすのではなく、マーチャントが入力を始める前に、パスワードの要件をすべて示します。これにより、ストレスやフォームの離脱を防げます。
- **パスワードを作成するマーチャントを導く。** 文脈なしにルールを強制するのではなく、パスワードの強度をリアルタイムでフィードバックし、どうすればより強くなるかを説明します。
- **貼り付けを許可する。** パスワードマネージャーなどのツールは貼り付けに依存しており、貼り付けをブロックすると、マーチャントは記憶して入力できる弱いパスワードを選びがちになります。
- **クライアント側のチェックはフィードバックとしてだけ扱う。** ブラウザの制約は簡単に回避できるため、パスワードは必ずサーバーで検証します。クライアント側の検証はすばやく応答するためのものであり、セキュリティを提供するものではありません。

```vue
<SPasswordField label="New password" autocomplete="new-password" details="Use at least 12 characters." />
```

詳しいガイダンスについては、[`<s-password-field>` に関する Shopify のベストプラクティス](https://shopify.dev/docs/api/app-home/latest/web-components/forms/password-field#best-practices)（英語）を参照してください。
