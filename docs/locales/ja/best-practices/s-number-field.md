- **純粋な数値だけに使う。** 数量、寸法、パーセンテージなどに使います。商品コードや電話番号のように、値に文字や記号が含まれうる場合は、代わりに `STextField` を使います。
- **単位を示す。** `prefix` または `suffix` で数値が何を表すのかを示し、ドル、キログラム、パーセンテージのどれを入力しているのかマーチャントが迷わないようにします。
- **ビジネスルールに合った制限を設定する。** 実際に許可される範囲を反映した `min` と `max` を設定し、フォームの送信前に有効な入力へとマーチャントを導きます。
- **検証し、エラーを説明する。** すべての数値入力をチェックし、問題があるときは、汎用的なメッセージを表示するのではなく、`error` で何が問題でどう直せばよいかを正確に伝えます。

```vue
<SNumberField label="Discount" suffix="%" :min="0" :max="100" />
```

詳しいガイダンスについては、[`<s-number-field>` に関する Shopify のベストプラクティス](https://shopify.dev/docs/api/app-home/latest/web-components/forms/number-field#best-practices)（英語）を参照してください。
