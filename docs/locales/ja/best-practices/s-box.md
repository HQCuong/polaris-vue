- **汎用コンテナとして使う。** `SBox` は、コンテンツをグループ化するための余白、ボーダー、背景を扱います。行や列のような特定の配置が必要な場合は、代わりに `SStack` または `SGrid` を使います。
- **まず、より意味のあるコンポーネントがないか確認する。** `SSection` や `SBanner` のように、コンテンツが何であるかをすでに表すコンポーネントがあれば、そちらを優先します。専用のコンポーネントのほうが意図が明確で、アクセシビリティにも優れています。
- **小さな画面を考慮する。** デスクトップで問題なく見えるレイアウトもモバイルでは崩れることがあるため、固定サイズで決め打ちせず、レスポンシブな値で余白やレイアウトを調整します。
- **領域やインタラクティブなコンテンツを説明する。** ボックスが独立した領域を表す場合や、インタラクティブなコンテンツを含む場合は、`accessibilityRole` と `accessibilityLabel` を設定し、スクリーンリーダーのユーザーが構造を理解して移動できるようにします。
- **ネストは浅く保つ。** ボックスの中にボックスを重ねると、マークアップが複雑になり、スタイルの保守も難しくなります。よりシンプルな構造や、より適したレイアウトコンポーネントを検討してください。

```vue
<SBox accessibilityRole="region" accessibilityLabel="Shipping summary" padding="base" border="base">
  <!-- … -->
</SBox>
```

詳しいガイダンスについては、[`<s-box>` に関する Shopify のベストプラクティス](https://shopify.dev/docs/api/app-home/latest/web-components/layout-and-structure/box#best-practices)（英語）を参照してください。
