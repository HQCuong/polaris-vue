- **妥当な日付から始める。** `value` をあらかじめ入れておき、マーチャントがすばやく選択できるようにします。
- **よく使う選択にはショートカットを用意する。** 「Today」「Last 7 days」「This month」のようなプリセットがあれば、マーチャントはカレンダーをクリックして移動する手間が省けます。
- **開始日と終了日には `type="range"` を使う。** 範囲選択は、レポート、分析、その他の期間に基づくフィルターに適しています。
- **当てはまらない日付はブロックする。** `allow` と `disallow` を使い、ユースケース上無効な日付をマーチャントが選べないようにします。
- **ピッカーの周りに余白を取る。** オンスクリーンキーボードや他のインタラクティブな要素の邪魔にならないよう、十分なスペースを確保します。
- **遠い日付を考慮する。** 数年を超えると月ごとのページ送りは面倒になるため、おおよそ 5〜10 年の範囲外の日付には、プリセットを用意するか、マーチャントが年を直接入力できるようにします。

```vue
<SDatePicker type="range" />
```

詳しいガイダンスについては、[`<s-date-picker>` に関する Shopify のベストプラクティス](https://shopify.dev/docs/api/app-home/latest/web-components/forms/date-picker#best-practices)（英語）を参照してください。
