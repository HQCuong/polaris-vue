- **アイコンは装飾ではなく情報のために使う。** 削除アクションの削除アイコンや、完了したものを示すチェックマークのように、アイコンはアクションの内容を説明したり、状態を示したりするものです。見た目のためだけにアイコンを追加しないでください。
- **一貫性を保つ。** あるアイコンが特定のアクションや概念を表すと決めたら、アプリ全体でその意味を保ちます。ある場所で `edit` が編集を意味するなら、すべての場所で編集に使います。
- **できるだけアイコンとテキストを組み合わせる。** よく知られたアイコンでも、単独では複数の意味に解釈されることがあります。アイコンを単独で使うのは、`accessibilityLabel` を付けたアイコンのみのボタンのように、スペースが限られる場合だけにします。
- **広く認知されたアイコンを選ぶ。** `search`、`delete`、`plus` のように意味が定着したアイコンを優先します。説明が必要なアイコンなら、別のものを選びます。
- **`tone` で意味を伝える。** 破壊的なアクションには `tone="critical"`、肯定的な状態には `tone="success"`、注意には `tone="warning"` を使います。トーンは装飾ではなく、何かを伝えるためのものです。

```vue
<SIcon type="alert-triangle" tone="warning" />
```

詳しいガイダンスについては、[`<s-icon>` に関する Shopify のベストプラクティス](https://shopify.dev/docs/api/app-home/latest/web-components/media-and-visuals/icon#best-practices)（英語）を参照してください。
