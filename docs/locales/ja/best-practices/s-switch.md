- **スイッチと保存ボタンを組み合わせない。** スイッチは切り替えた瞬間に反映されるため、保存ボタンを追加すると、変更がいつ実際に適用されるのかマーチャントが判断できなくなります。
- **設定内容をわかりやすくする。** スイッチが何を制御し、オンとオフが何を意味するのかを伝える `label` を書き、確かめるためだけに切り替える必要がないようにします。
- **結果を説明する。** 特に重要な機能やデータに影響する設定では、`details` を使ってスイッチを切り替えると何が変わるのかを説明し、マーチャントが自信を持って判断できるようにします。
- **関連するスイッチをまとめて並べる。** ページに複数のスイッチがある場合は、関連する設定を論理的な順序でまとめ、マーチャントが簡単に見つけて設定できるようにします。
- **スイッチが使えない理由を説明する。** 権限、依存関係、プランの制限によってスイッチが `disabled` になっている場合は、その理由、一時的なものかどうか、そして使えるようにするには何をすればよいかをマーチャントに伝えます。

```vue
<SSwitch label="Send order confirmation emails" details="Customers get an email as soon as they place an order." />
```

詳しいガイダンスについては、[`<s-switch>` に関する Shopify のベストプラクティス](https://shopify.dev/docs/api/app-home/latest/web-components/forms/switch#best-practices)（英語）を参照してください。
