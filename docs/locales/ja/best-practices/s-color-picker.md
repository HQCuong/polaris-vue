- **現在の色から始める。** マーチャントが既存の色を編集するときは、`value` にその色を設定し、迷わずに何から変更するのかを確認できるようにします。
- **色をコンテキストの中でプレビューする。** 可能であれば、選んだ色をボタンなど影響を受ける対象に適用した状態で、ピッカーの横に表示します。
- **正確な値には `SColorField` と組み合わせる。** ピッカーは見た目で選ぶのに適しており、カラーフィールドではマーチャントが正確な 16 進数の値を入力できます。

詳しいガイダンスについては、[`<s-color-picker>` に関する Shopify のベストプラクティス](https://shopify.dev/docs/api/app-home/latest/web-components/forms/color-picker#best-practices)（英語）を参照してください。
