- **Mit einem sinnvollen Datum beginnen.** Füllen Sie `value` beim Bearbeiten mit dem bestehenden Datum vor oder mit einer wahrscheinlichen Wahl, wenn Sie einen Vorschlag machen.
- **Daten auf das Sinnvolle beschränken.** Grenzen Sie mit `allow` und `disallow` ein, welche Daten Händler wählen können, etwa nur künftige Termine für ein Planungsfeld oder Montag bis Freitag für ein geschäftliches Feld.
- **Einschränkungen in `details` erklären.** Nennen Sie Anforderungen wie „Must be a future date“, damit Händler die Regeln vor der Auswahl kennen.
- **`error`-Meldungen umsetzbar formulieren.** Ist ein Datum ungültig, sagen Sie Händlern, wie sie es korrigieren.

Die vollständigen Richtlinien finden sich in [Shopifys Best Practices für `<s-date-field>`](https://shopify.dev/docs/api/app-home/latest/web-components/forms/date-field#best-practices) (auf Englisch).
