- **Verwenden, wenn die Reihenfolge keine Rolle spielt.** Eine ungeordnete Liste stellt zusammengehörige Elemente wie Funktionen, Optionen oder Vorteile ohne Reihenfolge oder Rangfolge dar. Kommt es auf die Reihenfolge an, verwenden Sie stattdessen `SOrderedList`.
- **Einträge parallel formulieren.** Geben Sie jedem Eintrag dieselbe grammatische Struktur, damit sich die Liste leicht überfliegen lässt. Gemischte Schreibstile in einer Liste erschweren das Lesen.
- **Kurze Einträge schreiben.** Listen funktionieren am besten, wenn jeder Eintrag knapp ist. Werden Einträge lang oder komplex, erwägen Sie, den Inhalt in separate Abschnitte aufzuteilen.
- **Verschachtelung begrenzen.** Verschachtelte Listen können hierarchische Inhalte ordnen, werden aber schnell unübersichtlich. Brauchen Sie mehr als zwei Ebenen, eignet sich der Inhalt möglicherweise nicht für eine Liste.

Die vollständigen Richtlinien finden sich in [Shopifys Best Practices für `<s-unordered-list>`](https://shopify.dev/docs/api/app-home/latest/web-components/layout-and-structure/unordered-list#best-practices) (auf Englisch).
