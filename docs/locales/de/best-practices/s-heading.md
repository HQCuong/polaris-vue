- **Jedem wichtigen Abschnitt eine Überschrift geben.** Überschriften bilden eine Gliederung der Oberfläche, die Händlern bei der Orientierung hilft und zeigt, wie Inhalte organisiert sind.
- **Die Komponente die Überschriftenebene wählen lassen.** Sie vergibt die HTML-Ebene (h2, h3, h4) anhand der Verschachtelungstiefe, sodass Screenreader eine korrekte Dokumentstruktur erhalten, ohne dass Ebenen von Hand gesetzt werden müssen.
- **Konkret sein.** Sagen Sie, worum es im Abschnitt geht, zum Beispiel „Product details“ oder „Customer details“ statt nur „Details“.
- **Zeilen nur kürzen, wenn es sein muss.** `lineClamp` kann lange Überschriften auf engem Raum wie in Cards bändigen, aber eine gekürzte Überschrift kann Informationen verbergen, die Händler brauchen.
- **Ähnliche Überschriften gleich gestalten.** Überschriften für dieselbe Art von Inhalt, etwa für jede Card in einer Liste, sollten gleich aussehen.

Die vollständigen Richtlinien finden sich in [Shopifys Best Practices für `<s-heading>`](https://shopify.dev/docs/api/app-home/latest/web-components/typography-and-content/heading#best-practices) (auf Englisch).
