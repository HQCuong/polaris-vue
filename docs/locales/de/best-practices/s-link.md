- **Nur externe Links in einem neuen Tab öffnen.** Setzen Sie `target="_blank"` für URLs außerhalb des Adminbereichs, etwa Hilfedokumente oder Partnerseiten. Links innerhalb des Adminbereichs sollten im selben Tab bleiben, damit Händler ihren Platz im Arbeitsablauf behalten.

Die vollständigen Richtlinien finden sich in [Shopifys Best Practices für `<s-link>`](https://shopify.dev/docs/api/app-home/latest/web-components/actions/link#best-practices) (auf Englisch).
