- **Kleinere Bildschirme einplanen.** Ein Grid, das auf dem Desktop funktioniert, kann mobil zerfallen. Legen Sie fest, wie es sich bei geringerer Breite neu umbricht oder anordnet, statt ein einziges Layout festzuschreiben.
- **Einheitliche Abstände verwenden.** Gleichmäßige Abstände zwischen Elementen geben dem Layout einen ruhigen Rhythmus und erleichtern das Überfliegen. Mischen Sie daher keine verschiedenen Abstandsansätze innerhalb eines Grids.
- **Inhalte einplanen, die nicht passen.** Zellen haben feste Maße, Inhalte aber unterschiedliche Längen. Entscheiden Sie im Voraus, ob zu langer oder zu breiter Inhalt umbrechen, abgeschnitten werden oder scrollen soll.
- **Eine einfachere Komponente verwenden, wenn sie genügt.** `SGrid` ist leistungsfähig, bringt aber Komplexität mit. Prüfen Sie, ob eine einfachere Layout-Komponente reicht, und nutzen Sie das Grid für Fälle, die seine Möglichkeiten wirklich brauchen.

Die vollständigen Richtlinien finden sich in [Shopifys Best Practices für `<s-grid>`](https://shopify.dev/docs/api/app-home/latest/web-components/layout-and-structure/grid#best-practices) (auf Englisch).
