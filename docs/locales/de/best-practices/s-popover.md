- **Für sekundäre Inhalte verwenden.** Ein Popover bleibt verborgen, bis Händler es öffnen. Legen Sie daher weniger wichtige Informationen und Aktionen hinein, nichts, was sofort sichtbar sein muss.
- **Zusammengehörige Aktionen gruppieren.** Die Aktionen in einem Popover sollten zusammengehören.
- **Über einen klar beschrifteten Button öffnen.** Lösen Sie das Popover mit einem Standard- oder `variant="tertiary"`-`SButton` aus, dessen Label sagt, was sich darin befindet.

Die vollständigen Richtlinien finden sich in [Shopifys Best Practices für `<s-popover>`](https://shopify.dev/docs/api/app-home/latest/web-components/overlays/popover#best-practices) (auf Englisch).
