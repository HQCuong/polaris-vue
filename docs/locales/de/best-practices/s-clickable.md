- **Elemente ohne sichtbaren Text beschriften.** Enthält der klickbare Bereich keinen lesbaren Text, setzen Sie `accessibilityLabel`, damit Screenreader-Nutzer wissen, wofür er da ist.
- **Den passenden Modus wählen.** Als Button löst es Aktionen aus, mit `href` navigiert es, und mit `type="submit"` sendet es ein Formular ab.
- **Deaktivierte Zustände erklären.** Wenn Sie `disabled` setzen, machen Sie den Zustand visuell deutlich und ergänzen Sie einen Text, der Händlern erklärt, warum das Element nicht nutzbar ist.

Die vollständigen Richtlinien finden sich in [Shopifys Best Practices für `<s-clickable>`](https://shopify.dev/docs/api/app-home/latest/web-components/actions/clickable#best-practices) (auf Englisch).
