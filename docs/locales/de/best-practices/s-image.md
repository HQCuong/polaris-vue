- **Scharfe, optimierte Bilder verwenden.** Wählen Sie hochauflösende Bilder, die zugleich für das Web optimiert sind.
- **Bilder gezielt einsetzen.** Fügen Sie ein Bild nur hinzu, wenn es den Inhalt verständlicher macht oder Händlern Orientierung gibt.

Die vollständigen Richtlinien finden sich in [Shopifys Best Practices für `<s-image>`](https://shopify.dev/docs/api/app-home/latest/web-components/media-and-visuals/image#best-practices) (auf Englisch).
