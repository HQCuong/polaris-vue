- **`size="small-200"` für die engsten Stellen.** Verwenden Sie es nur, wo der Platz sehr begrenzt ist.
- **`size="small"` für kleine Flächen.** Verwenden Sie es, wenn das Thumbnail in einen kompakten Bereich passen muss.
- **`size="base"` als Standard.** Beginnen Sie hiermit, sofern das Layout nichts anderes verlangt.
- **`size="large"`, wenn das Bild im Mittelpunkt steht.** Verwenden Sie es, wenn das Thumbnail der Hauptblickfang ist.

Die vollständigen Richtlinien finden sich in [Shopifys Best Practices für `<s-thumbnail>`](https://shopify.dev/docs/api/app-home/latest/web-components/media-and-visuals/thumbnail#best-practices) (auf Englisch).
