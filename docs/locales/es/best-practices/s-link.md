- **Abre solo los enlaces externos en una pestaña nueva.** Define `target="_blank"` para las URL fuera del admin de Shopify, como la documentación de ayuda o los sitios de socios. Los enlaces dentro del admin de Shopify deben quedarse en la misma pestaña para que los comerciantes no pierdan su lugar en el flujo de trabajo.

Consulta [las buenas prácticas de Shopify para `<s-link>`](https://shopify.dev/docs/api/app-home/latest/web-components/actions/link#best-practices) (en inglés) para ver todas las recomendaciones.
