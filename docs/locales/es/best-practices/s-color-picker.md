- **Parte del color actual.** Cuando los comerciantes editen un color existente, define `value` con ese color para que no pierdan la referencia y vean desde qué color parten.
- **Previsualiza el color en contexto.** Siempre que puedas, muestra junto al selector el color elegido aplicado a lo que afecta, como un botón.
- **Combínalo con `SColorField` para valores exactos.** El selector sirve para elegir visualmente, mientras que un campo de color permite a los comerciantes escribir un valor hexadecimal preciso.

Consulta [las buenas prácticas de Shopify para `<s-color-picker>`](https://shopify.dev/docs/api/app-home/latest/web-components/forms/color-picker#best-practices) (en inglés) para ver todas las recomendaciones.
