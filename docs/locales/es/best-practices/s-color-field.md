- **Indica para qué sirve el color.** Usa un `label` como "Button background color" o "Heading text color" en lugar de un genérico "Color".
- **Muestra el color actual al editar.** Define `value` con el color existente para que los comerciantes vean desde qué color parten.

```vue
<SColorField label="Button background color" value="#1a1a1a" />
```

Consulta [las buenas prácticas de Shopify para `<s-color-field>`](https://shopify.dev/docs/api/app-home/latest/web-components/forms/color-field#best-practices) (en inglés) para ver todas las recomendaciones.
