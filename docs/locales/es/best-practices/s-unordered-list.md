- **Úsala cuando el orden no importa.** Una lista no ordenada presenta elementos relacionados, como funciones, opciones o ventajas, sin secuencia ni clasificación. Cuando el orden importe, usa `SOrderedList` en su lugar.
- **Mantén los elementos paralelos.** Da a cada elemento la misma estructura gramatical para que la lista sea fácil de revisar. Mezclar estilos de redacción en una misma lista la hace más difícil de leer.
- **Escribe elementos cortos.** Las listas funcionan mejor cuando cada elemento es breve. Si los elementos se vuelven largos o complejos, considera dividir el contenido en secciones separadas.
- **Limita el anidamiento.** Las listas anidadas pueden organizar contenido jerárquico, pero enseguida se vuelven difíciles de seguir. Si necesitas más de dos niveles, puede que el contenido no sea adecuado para una lista.

Consulta [las buenas prácticas de Shopify para `<s-unordered-list>`](https://shopify.dev/docs/api/app-home/latest/web-components/layout-and-structure/unordered-list#best-practices) (en inglés) para ver todas las recomendaciones.
