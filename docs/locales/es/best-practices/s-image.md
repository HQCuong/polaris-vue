- **Usa imágenes nítidas y optimizadas.** Elige imágenes de alta resolución que también estén optimizadas para la web.
- **Añade imágenes con un propósito.** Incluye una imagen solo cuando aclare el contenido o ayude a guiar a los comerciantes.
