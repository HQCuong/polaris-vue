- **Etiqueta los elementos sin texto visible.** Si dentro del área clicable no hay texto legible, define `accessibilityLabel` para que los usuarios de lectores de pantalla sepan para qué sirve.
- **Elige el modo adecuado.** Úsalo como botón para desencadenar acciones, dale un `href` para navegar y define `type="submit"` cuando envíe un formulario.
- **Explica los estados deshabilitados.** Cuando definas `disabled`, deja el estado claro visualmente y añade un texto que explique a los comerciantes por qué no se puede usar el elemento.

Consulta [las buenas prácticas de Shopify para `<s-clickable>`](https://shopify.dev/docs/api/app-home/latest/web-components/actions/clickable#best-practices) (en inglés) para ver todas las recomendaciones.
