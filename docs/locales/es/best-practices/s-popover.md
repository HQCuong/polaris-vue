- **Resérvalo para contenido secundario.** Un popover permanece oculto hasta que los comerciantes lo abren, así que coloca en él información y acciones menos importantes, nada que necesiten ver de inmediato.
- **Agrupa las acciones relacionadas.** Las acciones dentro de un popover deben estar relacionadas entre sí.
- **Ábrelo desde un botón con una etiqueta clara.** Activa el popover con un `SButton` predeterminado o con `variant="tertiary"` cuya etiqueta indique qué contiene.

Consulta [las buenas prácticas de Shopify para `<s-popover>`](https://shopify.dev/docs/api/app-home/latest/web-components/overlays/popover#best-practices) (en inglés) para ver todas las recomendaciones.
