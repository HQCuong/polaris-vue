- **`size="small-200"` pour les espaces les plus restreints.** Ne l'utilisez que là où la place est très limitée.
- **`size="small"` pour les petits espaces.** Utilisez-la lorsque la miniature doit tenir dans une zone compacte.
- **`size="base"` par défaut.** Commencez par celle-ci, sauf si la mise en page exige autre chose.
- **`size="large"` lorsque l'image est au centre.** Utilisez-la lorsque la miniature est le principal point d'attention.

Consultez [les bonnes pratiques de Shopify pour `<s-thumbnail>`](https://shopify.dev/docs/api/app-home/latest/web-components/media-and-visuals/thumbnail#best-practices) (en anglais) pour l'ensemble des recommandations.
