- **Donnez un titre à chaque section importante.** Les titres forment un plan de l'interface qui aide les marchands à s'orienter et à comprendre l'organisation du contenu.
- **Laissez le composant choisir le niveau de titre.** Il attribue le niveau HTML (h2, h3, h4) selon la profondeur d'imbrication, si bien que les lecteurs d'écran obtiennent une structure de document correcte sans que vous ayez à définir les niveaux à la main.
- **Soyez précis.** Dites ce que couvre la section, par exemple "Product details" ou "Customer details" plutôt que simplement "Details".
- **Ne limitez le nombre de lignes qu'en cas de nécessité.** `lineClamp` peut contenir les titres longs dans les espaces restreints comme les cartes, mais tronquer un titre peut masquer des informations dont les marchands ont besoin.
- **Stylisez de la même façon les titres similaires.** Les titres d'un même type de contenu, comme chaque carte d'une liste, doivent se ressembler.

Consultez [les bonnes pratiques de Shopify pour `<s-heading>`](https://shopify.dev/docs/api/app-home/latest/web-components/typography-and-content/heading#best-practices) (en anglais) pour l'ensemble des recommandations.
