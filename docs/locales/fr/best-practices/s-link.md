- **N'ouvrez que les liens externes dans un nouvel onglet.** Définissez `target="_blank"` pour les URL extérieures à l'interface d'administration, comme la documentation d'aide ou les sites partenaires. Les liens internes à l'interface d'administration doivent rester dans le même onglet pour que les marchands ne perdent pas le fil de leur travail.

Consultez [les bonnes pratiques de Shopify pour `<s-link>`](https://shopify.dev/docs/api/app-home/latest/web-components/actions/link#best-practices) (en anglais) pour l'ensemble des recommandations.
