- **Dê um título a cada seção principal.** Os títulos formam um esboço da interface que ajuda os lojistas a se orientarem e a ver como o conteúdo está organizado.
- **Deixe o componente escolher o nível do título.** Ele atribui o nível HTML (h2, h3, h4) conforme a profundidade de aninhamento, para que os leitores de tela recebam uma estrutura de documento correta sem que você defina os níveis manualmente.
- **Seja específico.** Diga o que a seção abrange, por exemplo "Detalhes do produto" ou "Detalhes do cliente" em vez de apenas "Detalhes".
- **Limite as linhas só quando for preciso.** `lineClamp` pode domar títulos longos em espaços apertados como cards, mas cortar um título pode esconder informações de que os lojistas precisam.
- **Estilize títulos semelhantes da mesma forma.** Títulos para o mesmo tipo de conteúdo, como todos os cards de uma lista, devem ter a mesma aparência.

Veja [as boas práticas da Shopify para `<s-heading>`](https://shopify.dev/docs/api/app-home/latest/web-components/typography-and-content/heading#best-practices) (em inglês) para todas as recomendações.
