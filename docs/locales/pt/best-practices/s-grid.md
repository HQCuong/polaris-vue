- **Pense nas telas menores.** Um grid que funciona no desktop pode desmoronar no celular. Decida como ele deve se reorganizar em larguras menores em vez de fixar um único layout.
- **Use um espaçamento consistente.** Espaços uniformes entre os itens dão ao layout um ritmo estável e facilitam a leitura, então evite misturar abordagens de espaçamento dentro de um mesmo grid.
- **Considere o conteúdo que não cabe.** As células têm dimensões definidas, mas o tamanho do conteúdo varia. Decida de antemão se um conteúdo longo ou largo demais deve quebrar linha, ser truncado ou rolar.
- **Use um componente mais simples quando ele bastar.** `SGrid` é poderoso, mas acrescenta complexidade, então verifique se um componente de layout mais simples resolve e reserve o grid para os casos que precisam do que ele oferece.

Veja [as boas práticas da Shopify para `<s-grid>`](https://shopify.dev/docs/api/app-home/latest/web-components/layout-and-structure/grid#best-practices) (em inglês) para todas as recomendações.
