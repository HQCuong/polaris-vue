- **`size="small-200"` para os espaços mais apertados.** Recorra a ele apenas onde o espaço for muito limitado.
- **`size="small"` para espaços pequenos.** Use quando a miniatura precisar caber em uma área compacta.
- **`size="base"` por padrão.** Comece por aqui, a menos que o layout peça outra coisa.
- **`size="large"` quando a imagem for o foco.** Use quando a miniatura for o principal ponto de atenção.
