- **Use imagens nítidas e otimizadas.** Escolha imagens de alta resolução que também sejam otimizadas para a web.
- **Adicione imagens com um propósito.** Inclua uma imagem apenas quando ela deixar o conteúdo mais claro ou ajudar a orientar os lojistas.

Veja [as boas práticas da Shopify para `<s-image>`](https://shopify.dev/docs/api/app-home/latest/web-components/media-and-visuals/image#best-practices) (em inglês) para todas as recomendações.
