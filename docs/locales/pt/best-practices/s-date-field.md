- **Comece com uma data sensata.** Preencha `value` com a data existente ao editar, ou com uma opção provável ao sugerir uma.
- **Limite as datas ao que faz sentido.** Restrinja as datas que os lojistas podem escolher com `allow` e `disallow`, como limitar um campo de agendamento a datas futuras ou um campo comercial a dias de segunda a sexta.
- **Explique os limites em `details`.** Deixe claros requisitos como "Deve ser uma data futura" para que os lojistas conheçam as regras antes de escolher.
- **Torne as mensagens de `error` acionáveis.** Quando uma data for inválida, diga aos lojistas como corrigi-la.

Veja [as boas práticas da Shopify para `<s-date-field>`](https://shopify.dev/docs/api/app-home/latest/web-components/forms/date-field#best-practices) (em inglês) para todas as recomendações.
