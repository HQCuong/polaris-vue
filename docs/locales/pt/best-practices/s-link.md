- **Abra em nova aba apenas links externos.** Defina `target="_blank"` para URLs fora do admin, como documentação de ajuda ou sites de parceiros. Links dentro do admin devem permanecer na mesma aba para que os lojistas não percam o ponto em que estão no fluxo de trabalho.

Veja [as boas práticas da Shopify para `<s-link>`](https://shopify.dev/docs/api/app-home/latest/web-components/actions/link#best-practices) (em inglês) para todas as recomendações.
