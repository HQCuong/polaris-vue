- **Rotule elementos sem texto visível.** Se nada dentro da área clicável for texto legível, defina `accessibilityLabel` para que os usuários de leitores de tela saibam para que ela serve.
- **Escolha o modo adequado.** Use-o como botão para acionar ações, dê a ele um `href` para navegar e defina `type="submit"` quando ele enviar um formulário.
- **Explique os estados desativados.** Ao definir `disabled`, deixe o estado visualmente claro e adicione um texto que diga aos lojistas por que o elemento não pode ser usado.

Veja [as boas práticas da Shopify para `<s-clickable>`](https://shopify.dev/docs/api/app-home/latest/web-components/actions/clickable#best-practices) (em inglês) para todas as recomendações.
