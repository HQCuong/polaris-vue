- **Use quando a ordem não importar.** Uma lista não ordenada apresenta itens relacionados, como recursos, opções ou benefícios, sem sequência nem classificação. Quando a sequência importar, use `SOrderedList` no lugar.
- **Mantenha os itens paralelos.** Dê a todos os itens a mesma estrutura gramatical para que a lista seja fácil de percorrer. Misturar estilos de escrita em uma lista dificulta a leitura.
- **Escreva itens curtos.** Listas funcionam melhor quando cada item é breve. Se os itens ficarem longos ou complexos, considere dividir o conteúdo em seções separadas.
- **Limite o aninhamento.** Listas aninhadas podem organizar conteúdo hierárquico, mas logo ficam difíceis de acompanhar. Se você precisar de mais de dois níveis, talvez o conteúdo não seja adequado para uma lista.
