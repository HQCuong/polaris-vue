- **Diga para que serve a cor.** Use um `label` como "Cor de fundo do botão" ou "Cor do texto do título" em vez de um genérico "Cor".
- **Mostre a cor atual ao editar.** Defina `value` com a cor existente para que os lojistas vejam o que estão alterando.

```vue
<SColorField label="Button background color" value="#1a1a1a" />
```

Veja [as boas práticas da Shopify para `<s-color-field>`](https://shopify.dev/docs/api/app-home/latest/web-components/forms/color-field#best-practices) (em inglês) para todas as recomendações.
