- **Comece pela cor atual.** Quando os lojistas editarem uma cor existente, defina `value` com ela para que eles não percam a referência e vejam o que estão alterando.
- **Mostre a cor no contexto.** Sempre que possível, mostre ao lado do seletor a cor escolhida aplicada ao que ela afeta, como um botão.
- **Combine-o com `SColorField` para valores exatos.** O seletor é bom para escolher visualmente, enquanto um campo de cor permite que os lojistas digitem um valor hexadecimal preciso.

Veja [as boas práticas da Shopify para `<s-color-picker>`](https://shopify.dev/docs/api/app-home/latest/web-components/forms/color-picker#best-practices) (em inglês) para todas as recomendações.
