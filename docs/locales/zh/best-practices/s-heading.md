- **为每个主要部分设置标题。** 标题构成了界面的大纲，帮助商家找到方向并了解内容是如何组织的。
- **让组件决定标题级别。** 组件会根据嵌套深度分配 HTML 级别（h2、h3、h4），因此无需手动设置级别，屏幕阅读器就能获得正确的文档结构。
- **表述要具体。** 说明该部分的内容，例如用“产品详情”或“客户详情”，而不是只写“详情”。
- **只在必要时限制行数。** `lineClamp` 可以在卡片等狭小空间中控制较长的标题，但截断标题可能会隐藏商家需要的信息。
- **同类标题使用相同样式。** 同类内容的标题（例如列表中每张卡片的标题）应保持一致的外观。

参阅 [Shopify 关于 `<s-heading>` 的最佳实践](https://shopify.dev/docs/api/app-home/latest/web-components/typography-and-content/heading#best-practices)（英文）以获取完整指南。
