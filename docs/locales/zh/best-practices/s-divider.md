- **只分隔确实不同的内容。** 分隔线适合放在明显不同的部分之间。过多的分隔线会让界面显得杂乱、零碎，因此请先考虑留白是否同样能将内容分组。
- **让分隔线的粗细与分隔的程度相称。** 分隔线的醒目程度应反映分隔的重要性：主要部分之间可以使用 `color="strong"`，而次要分组只需一条更淡的线或仅用间距。
- **顺应布局的方向。** 设置 `direction`，让分隔线横贯它所分隔内容的排列方向，无论这些项目是垂直堆叠还是水平并排。
- **先尝试使用间距。** 布局组件上的间距 props 通常比一条线更能干净地将内容分组。添加分隔线是为了让内容更清晰，而不是用来代替精心规划的间距。
