- **从当前颜色开始。** 当商家编辑现有颜色时，将 `value` 设为该颜色，让他们心中有数，并能看到自己正在修改的原始值。
- **在实际场景中预览颜色。** 尽可能在取色器旁边展示所选颜色应用到受影响元素（例如按钮）上的效果。
- **搭配 `SColorField` 输入精确值。** 取色器适合直观地挑选颜色，而颜色字段可以让商家输入精确的十六进制值。
