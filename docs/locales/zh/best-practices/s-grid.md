- **为小屏幕做好规划。** 在桌面端可行的网格可能在移动端崩溃。请规划它在较窄宽度下如何重新排列，而不是固定一种布局。
- **使用统一的间距。** 项目之间均匀的间隙能让布局节奏稳定、更易浏览，因此不要在同一个网格中混用不同的间距方式。
- **考虑放不下的内容。** 单元格的尺寸是固定的，但内容长度各不相同。请事先决定过长或过宽的内容是换行、截断还是滚动。
- **简单组件够用时就用简单组件。** `SGrid` 功能强大但会增加复杂度，因此请先看看更简单的布局组件能否满足需求，把网格留给真正需要其能力的场景。

参阅 [Shopify 关于 `<s-grid>` 的最佳实践](https://shopify.dev/docs/api/app-home/latest/web-components/layout-and-structure/grid#best-practices)（英文）以获取完整指南。
