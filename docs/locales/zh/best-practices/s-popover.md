- **用于次要内容。** popover 在商家打开之前一直是隐藏的，因此请将不太重要的信息和操作放在其中，而不是任何需要立即看到的内容。
- **将相关操作分组。** popover 中的操作应彼此相关。
- **通过标签清晰的按钮打开。** 使用默认样式或 `variant="tertiary"` 的 `SButton` 来触发 popover，并让按钮标签说明其中的内容。

参阅 [Shopify 关于 `<s-popover>` 的最佳实践](https://shopify.dev/docs/api/app-home/latest/web-components/overlays/popover#best-practices)（英文）以获取完整指南。
