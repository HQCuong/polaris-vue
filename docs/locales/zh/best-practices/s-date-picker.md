- **从合理的日期开始。** 预填 `value`，让商家能更快完成选择。
- **为常用选择提供快捷方式。** “今天”“最近 7 天”或“本月”等预设可以让商家无需在日历中逐页点击。
- **对开始和结束日期使用 `type="range"`。** 范围选择适合报表、数据分析以及其他基于时间段的筛选。
- **屏蔽不适用的日期。** 使用 `allow` 和 `disallow`，使商家无法选择对你的用例无效的日期。
- **在选择器周围留出空间。** 为其留出足够的空间，避免妨碍屏幕键盘或其他交互元素。
- **为较远的日期做好规划。** 跨越几年后逐月翻页会变得繁琐，因此对于大约 5–10 年范围之外的日期，请提供预设或允许商家直接输入年份。

```vue
<SDatePicker type="range" />
```
