- **Используйте значки, чтобы информировать, а не украшать.** Значок должен объяснять, что делает действие, или показывать состояние: значок удаления на действии удаления или галочка у выполненного. Не добавляйте значки ради внешнего вида.
- **Будьте последовательны.** Если значок обозначает действие или понятие, сохраняйте это во всём приложении. Если `edit` означает редактирование в одном месте, используйте его для редактирования везде.
- **Сочетайте значки с текстом, когда это возможно.** Сами по себе даже знакомые значки могут пониматься по-разному. Используйте значок без текста только там, где мало места, например в кнопке только со значком с `accessibilityLabel`.
- **Выбирайте широко узнаваемые значки.** Отдавайте предпочтение значкам с устоявшимся смыслом, таким как `search`, `delete` и `plus`. Если значок нужно объяснять, выберите другой.
- **Пусть `tone` несёт смысл.** Используйте `tone="critical"` для деструктивных действий, `tone="success"` для положительных состояний и `tone="warning"` для предостережений. Тоны должны что-то сообщать, а не украшать.

```vue
<SIcon type="alert-triangle" tone="warning" />
```

Полное руководство см. в [рекомендациях Shopify для `<s-icon>`](https://shopify.dev/docs/api/app-home/latest/web-components/media-and-visuals/icon#best-practices) (на английском).
