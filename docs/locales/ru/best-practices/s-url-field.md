- **Проверяйте URL самостоятельно.** Встроенная проверка URL в браузере минимальна и различается между браузерами, поэтому добавьте собственные проверки структуры, допустимых протоколов и форматов, которые подходят для вашего случая.
- **Показывайте ожидаемый формат.** Сообщите продавцам, нужно ли указывать протокол, какие протоколы разрешены и какой вид URL вам нужен. Полный пример URL в `placeholder` делает это понятным.
- **Решите, как обрабатывать отсутствующий протокол.** Продавцы часто опускают `https://`. Выберите, добавлять ли его за них, принимать ли URL без него или показывать `error` с объяснением, чего не хватает.
- **Выбирайте ограничения длины с учётом места использования URL.** Браузеры и серверы поддерживают разную максимальную длину, поэтому задавайте `maxLength`, исходя из назначения URL, а не из произвольного числа, и упоминайте ограничение, когда это важно.
- **Объясните, для чего нужен URL.** Используйте `label` и `details`, чтобы прояснить назначение, ведь URL изображения товара, ссылка на профиль в соцсети и внешняя справка требуют разного.

```vue
<SUrlField label="Product image URL" placeholder="https://example.com/images/product.jpg" details="Link directly to a JPG or PNG file." />
```

Полное руководство см. в [рекомендациях Shopify для `<s-url-field>`](https://shopify.dev/docs/api/app-home/latest/web-components/forms/url-field#best-practices) (на английском).
