- **Используйте подсказки для дополнительных, необязательных сведений.** Они подходят для информации, которая помогает понять, но не обязательна. Никогда не прячьте в подсказке ошибки, важную информацию или обязательные инструкции.
- **Сочетайте их с кнопками только со значком.** Кнопке со значком нужна подсказка, объясняющая её действие; укажите действие и, если оно есть, сочетание клавиш.
- **Делайте текст кратким.** Идеальны короткая фраза или предложение. Если содержимое получается длинным, оно, вероятно, заслуживает более заметного места в интерфейсе.
- **Считайте обилие подсказок тревожным признаком.** Если интерфейсу нужно много подсказок, чтобы быть понятным, улучшите подписи, компоновку или информационную архитектуру.
- **Помните об устройствах с сенсорным экраном.** Подсказки работают только на десктопе и не появляются на сенсорных экранах, поэтому важную информацию на мобильных устройствах показывайте по умолчанию.

```vue
<SButton icon="delete" accessibilityLabel="Delete product" interestFor="delete-tip" />
<STooltip id="delete-tip">Delete product</STooltip>
```

Полное руководство см. в [рекомендациях Shopify для `<s-tooltip>`](https://shopify.dev/docs/api/app-home/latest/web-components/typography-and-content/tooltip#best-practices) (на английском).
