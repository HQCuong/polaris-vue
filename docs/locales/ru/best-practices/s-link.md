- **Открывайте в новой вкладке только внешние ссылки.** Задавайте `target="_blank"` для URL за пределами админки, например справочной документации или сайтов партнёров. Ссылки внутри админки должны открываться в той же вкладке, чтобы продавцы не теряли своё место в рабочем процессе.

Полное руководство см. в [рекомендациях Shopify для `<s-link>`](https://shopify.dev/docs/api/app-home/latest/web-components/actions/link#best-practices) (на английском).
