- **Укажите, для чего нужен цвет.** Используйте `label` вроде «Button background color» или «Heading text color» вместо общего «Color».
- **Показывайте текущий цвет при редактировании.** Задайте `value` существующим цветом, чтобы продавцы видели, от чего они отталкиваются.

```vue
<SColorField label="Button background color" value="#1a1a1a" />
```

Полное руководство см. в [рекомендациях Shopify для `<s-color-field>`](https://shopify.dev/docs/api/app-home/latest/web-components/forms/color-field#best-practices) (на английском).
