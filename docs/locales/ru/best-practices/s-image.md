- **Используйте чёткие, оптимизированные изображения.** Выбирайте изображения высокого разрешения, оптимизированные для веба.
- **Добавляйте изображения с целью.** Включайте изображение, только когда оно делает содержимое понятнее или помогает ориентировать продавцов.

Полное руководство см. в [рекомендациях Shopify для `<s-image>`](https://shopify.dev/docs/api/app-home/latest/web-components/media-and-visuals/image#best-practices) (на английском).
