- **Делайте абзацы короткими.** Стремитесь к двум-четырём предложениям простым языком без жаргона. Продавцы обычно просматривают текст по диагонали, поэтому разбивайте длинный контент на небольшие части.
- **Используйте tone, чтобы обозначить назначение.** `tone="critical"` подходит для ошибок, `"caution"` для предупреждений, а `"success"` для подтверждений. Всегда подкрепляйте цвет понятной формулировкой и не полагайтесь только на него.
- **Учитывайте доступность.** Добавляйте текст только для программ чтения с экрана (`accessibilityVisibility="exclusive"`) для контекста, который зрячие продавцы получают из компоновки или значков, и следите, чтобы текст с tone оставался достаточно контрастным.
- **Ограничивайте число строк осторожно.** `lineClamp` помогает в тесных местах, например в карточках или превью, но не позволяйте обрезке скрывать критически важную информацию.

Полное руководство см. в [рекомендациях Shopify для `<s-paragraph>`](https://shopify.dev/docs/api/app-home/latest/web-components/typography-and-content/paragraph#best-practices) (на английском).
