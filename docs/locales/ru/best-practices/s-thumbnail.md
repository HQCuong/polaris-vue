- **`size="small-200"` для самых тесных мест.** Используйте его, только когда места очень мало.
- **`size="small"` для небольших мест.** Используйте, когда миниатюра должна поместиться в компактную область.
- **`size="base"` по умолчанию.** Начинайте с него, если макет не требует другого.
- **`size="large"`, когда изображение в фокусе.** Используйте, когда миниатюра является главным объектом внимания.

Полное руководство см. в [рекомендациях Shopify для `<s-thumbnail>`](https://shopify.dev/docs/api/app-home/latest/web-components/media-and-visuals/thumbnail#best-practices) (на английском).
