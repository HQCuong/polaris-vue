- **Начинайте с текущего цвета.** Когда продавцы редактируют существующий цвет, задайте `value` этим цветом, чтобы они не терялись и видели, от чего отталкиваются.
- **Показывайте предпросмотр цвета в контексте.** Где возможно, показывайте выбранный цвет применённым к тому, на что он влияет, например к кнопке, рядом с палитрой.
- **Сочетайте его с `SColorField` для точных значений.** Палитра удобна для визуального выбора, а поле цвета позволяет продавцам ввести точное hex-значение.

Полное руководство см. в [рекомендациях Shopify для `<s-color-picker>`](https://shopify.dev/docs/api/app-home/latest/web-components/forms/color-picker#best-practices) (на английском).
