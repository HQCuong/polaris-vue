- **Используйте для известного набора вариантов.** Select подходит, когда продавец выбирает из заранее определённого списка. Если продавцу нужно ввести своё значение или искать по длинному списку, лучше подойдёт текстовое поле с подсказками при вводе или выпадающий список с поиском.
- **Упорядочивайте варианты осознанно.** Группируйте связанные варианты, ставьте самые частые первыми или сортируйте по алфавиту, если естественного порядка нет, чтобы продавец быстро находил нужное.
- **Пишите подписи, которые легко просматривать.** Давайте каждому варианту достаточно контекста, чтобы продавец мог различить варианты, не открывая и не перечитывая несколько из них.
- **Выбирайте начальное состояние намеренно.** Предварительно выбирайте вариант, если есть очевидное значение по умолчанию, и используйте `placeholder`, когда продавец должен сделать осознанный выбор. Не оставляйте начальное состояние неоднозначным.
- **Объясняйте проблемы с проверкой.** Если выбор обязателен или недопустим, используйте `error`, чтобы конкретно сказать продавцу, что делать, ведь подробные сообщения помогают заполнить формы быстрее, чем общие.

```vue
<SSelect label="Shipping speed" placeholder="Choose a shipping speed" required>
  <SOption value="standard">Standard (5–7 business days)</SOption>
  <SOption value="express">Express (2–3 business days)</SOption>
  <SOption value="overnight">Overnight (next business day)</SOption>
</SSelect>
```

Полное руководство см. в [рекомендациях Shopify для `<s-select>`](https://shopify.dev/docs/api/app-home/latest/web-components/forms/select#best-practices) (на английском).
