- **Подбирайте размер под контекст.** Используйте `size="base"` в ячейках таблиц, элементах списков и везде, где рядом стоит несколько бейджей. Оставьте `size="large"` для единственного бейджа, который заслуживает акцента, например основного статуса в верхней части страницы.
- **Ограничивайтесь одним-двумя словами.** Короткие подписи вроде «Fulfilled» или «Out of stock» легко просматриваются. Записывайте статусы в прошедшем времени: «Refunded», а не «Refund».
- **Подбирайте тон под статус.** Используйте `tone="critical"` для ошибок и срочных проблем, требующих действий, `tone="warning"` для проблем, требующих внимания, `tone="success"` для положительных подтверждений и `tone="info"` для нейтральных статусов. Один и тот же статус должен иметь один и тот же тон во всём приложении.
- **Размещайте бейджи рядом с тем, что они описывают.** В элементе списка ставьте бейдж рядом с заголовком. В таблице отведите бейджам отдельный столбец, чтобы продавцам было удобно его просматривать.
- **Используйте бейджи только для системных статусов.** Бейджи — это статичные индикаторы, которые задаёт система, поэтому не применяйте их для тегов, которые создают продавцы, и для элементов, которые можно удалить.

```vue
<SBadge tone="success">Fulfilled</SBadge>
<SBadge tone="warning">Partially refunded</SBadge>
```

Полное руководство см. в [рекомендациях Shopify для `<s-badge>`](https://shopify.dev/docs/api/app-home/latest/web-components/feedback-and-status-indicators/badge#best-practices) (на английском).
