- **Оборачивайте только само число.** Помещайте в `SNumber` само числовое значение, а слова вокруг него оставляйте в `SText` или `SParagraph`. Табличные цифры аккуратно выравнивают числа, но делают обычные слова неровными.
- **Сначала форматируйте значения в своём приложении.** `SNumber` управляет видом цифр, а не форматированием значения, поэтому добавляйте символы валют, десятичные знаки и разделители тысяч самостоятельно, в соответствии с локалью продавца.
- **Используйте tone, только если у числа есть статус.** Задавайте `tone`, когда само число о чём-то сигнализирует, например о закончившемся запасе. Если выделить каждое число, ни одно не будет выделяться.
- **Задавайте размер по важности.** Числу, которое продавец должен прочитать первым, например итогу, задайте больший `fontSize`, а второстепенные числа оставьте с размером по умолчанию.

```vue
<SText>Total: </SText><SNumber fontSize="large">$1,240.50</SNumber>
<SText>In stock: </SText><SNumber tone="critical">0</SNumber>
```

Полное руководство см. в [рекомендациях Shopify для `<s-number>`](https://shopify.dev/docs/api/app-home/latest/web-components/typography-and-content/number#best-practices) (на английском).
