- **Используйте, когда порядок не важен.** Маркированный список представляет связанные пункты, например возможности, варианты или преимущества, без последовательности или ранжирования. Если последовательность важна, используйте `SOrderedList`.
- **Делайте пункты параллельными.** Давайте каждому пункту одинаковую грамматическую структуру, чтобы список было легко просматривать. Смешение стилей в одном списке затрудняет чтение.
- **Пишите короткие пункты.** Списки лучше всего работают, когда каждый пункт краток. Если пункты становятся длинными или сложными, подумайте о разбиении контента на отдельные разделы.
- **Ограничивайте вложенность.** Вложенные списки могут упорядочить иерархический контент, но быстро становятся трудными для восприятия. Если нужно больше двух уровней, возможно, контент не подходит для списка.

Полное руководство см. в [рекомендациях Shopify для `<s-unordered-list>`](https://shopify.dev/docs/api/app-home/latest/web-components/layout-and-structure/unordered-list#best-practices) (на английском).
