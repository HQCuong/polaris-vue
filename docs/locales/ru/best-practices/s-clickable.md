- **Подписывайте элементы без видимого текста.** Если внутри кликабельной области нет читаемого текста, задайте `accessibilityLabel`, чтобы пользователи скринридеров знали её назначение.
- **Выбирайте подходящий режим.** Используйте его как кнопку для запуска действий, задайте `href` для перехода по ссылке и `type="submit"`, когда он отправляет форму.
- **Объясняйте отключённые состояния.** Когда вы задаёте `disabled`, сделайте состояние визуально понятным и добавьте текст, объясняющий продавцам, почему элемент недоступен.

Полное руководство см. в [рекомендациях Shopify для `<s-clickable>`](https://shopify.dev/docs/api/app-home/latest/web-components/actions/clickable#best-practices) (на английском).
