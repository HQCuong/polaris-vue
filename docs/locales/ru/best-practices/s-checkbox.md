- **Делайте каждый чекбокс независимым.** Продавцы должны иметь возможность отметить любое сочетание вариантов, и один чекбокс не должен влиять на другой.
- **Задавайте каждому чекбоксу понятный `label`.** Это особенно важно, когда чекбокс включает или выключает настройку, чтобы продавцы точно знали, что они включают.
- **Упорядочивайте варианты логично.** Сортируйте их по алфавиту, по числам или по времени, чтобы продавцы быстро находили нужный.
- **Применяйте `indeterminate` только для частичного «выбрать всё».** Используйте его на чекбоксе «выбрать всё», когда отмечена лишь часть элементов его группы.
- **Добавляйте `details`, когда это помогает.** Используйте его для дополнительного пояснения, что делает вариант, и только когда одной подписи недостаточно.

```vue
<SCheckbox
  label="Send order confirmation emails"
  details="Customers get an email as soon as their order is placed."
/>
```

Полное руководство см. в [рекомендациях Shopify для `<s-checkbox>`](https://shopify.dev/docs/api/app-home/latest/web-components/forms/checkbox#best-practices) (на английском).
