- **Давайте заголовок каждой крупной секции.** Заголовки образуют структуру интерфейса, которая помогает продавцам ориентироваться и понимать, как организовано содержимое.
- **Позвольте компоненту выбирать уровень заголовка.** Он назначает уровень HTML (h2, h3, h4) по глубине вложенности, так что скринридеры получают корректную структуру документа без ручной установки уровней.
- **Будьте конкретны.** Говорите, о чём секция, например «Product details» или «Customer details», а не просто «Details».
- **Ограничивайте число строк только при необходимости.** `lineClamp` может сократить длинные заголовки в тесных местах вроде карточек, но обрезанный заголовок способен скрыть нужную продавцам информацию.
- **Оформляйте похожие заголовки одинаково.** Заголовки для одного вида содержимого, например каждой карточки в списке, должны выглядеть одинаково.

Полное руководство см. в [рекомендациях Shopify для `<s-heading>`](https://shopify.dev/docs/api/app-home/latest/web-components/typography-and-content/heading#best-practices) (на английском).
