- **Задайте реалистичные значения `min` и `max`.** Например, цена товара может иметь `min` 0.01, чтобы её нельзя было сделать нулевой, скидка может лежать в диапазоне от 0 до суммы заказа, а возврат можно ограничить уплаченной суммой. Всегда проверяйте значения и по своим бизнес-правилам.
- **Укажите в `error` точное ограничение.** Вместо «Недопустимая сумма» напишите что-то вроде «Цена должна быть не меньше $0.01», чтобы продавец понял, какое ограничение нарушено.
- **Не добавляйте символы валют в `label` и `placeholder`.** Знак «$» или подобный может конфликтовать с форматированием валюты, которое поле уже выполняет.
- **Подписывайте сумму по её назначению.** «Базовая цена товара» или «Сумма скидки» сообщают продавцу больше, чем «Сумма» или «Цена».
- **Заполняйте `value` при редактировании.** Для существующих значений показывайте текущую сумму; для новых записей подумайте о разумном значении по умолчанию, например 0.00 или типичной цене.

```vue
<SMoneyField label="Product base price" :min="0.01" />
```

Полное руководство см. в [рекомендациях Shopify для `<s-money-field>`](https://shopify.dev/docs/api/app-home/latest/web-components/forms/money-field#best-practices) (на английском).
