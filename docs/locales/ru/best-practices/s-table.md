- **Используйте таблицы для данных, которые продавец сравнивает.** Таблицы подходят для множества записей с одинаковыми атрибутами, которые нужно просматривать бок о бок. Для простого списка, в котором нечего сравнивать, выберите более простой компонент.
- **Продумайте мобильный вид в виде списка.** На мобильных устройствах таблица превращается в список, поэтому убедитесь, что заголовки и значения по-прежнему хорошо читаются как составленные друг под другом пары «подпись и значение», а не как сетка.
- **Ограничивайте число столбцов.** Множество столбцов затрудняет просмотр таблицы и вынуждает прокручивать её по горизонтали. Показывайте только те столбцы, которые нужны продавцу для задачи, а остальные можно раскрывать по требованию.
- **Пишите понятные заголовки столбцов.** Делайте каждый `STableHeader` коротким и описательным, чтобы продавец точно знал, какие данные содержит столбец.
- **Продумайте большие наборы данных.** Большие таблицы вредят производительности и удобству. Включайте `paginate`, когда строк больше примерно 50–100, или подумайте о фильтрах или поиске, чтобы продавец быстрее добирался до нужных записей.

```vue
<STable paginate hasNextPage>
  <STableHeaderRow>
    <STableHeader>Product</STableHeader>
    <STableHeader format="numeric">Inventory</STableHeader>
  </STableHeaderRow>
  <STableBody>
    <STableRow>
      <STableCell>Snowboard</STableCell>
      <STableCell>24</STableCell>
    </STableRow>
  </STableBody>
</STable>
```

Полное руководство см. в [рекомендациях Shopify для `<s-table>`](https://shopify.dev/docs/api/app-home/latest/web-components/layout-and-structure/table#best-practices) (на английском).
