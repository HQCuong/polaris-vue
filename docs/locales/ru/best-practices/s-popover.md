- **Оставьте для второстепенного контента.** Popover скрыт, пока продавец его не откроет, поэтому размещайте в нём менее важную информацию и действия, а не то, что нужно увидеть сразу.
- **Группируйте связанные действия.** Действия внутри popover должны относиться друг к другу.
- **Открывайте его кнопкой с понятной подписью.** Вызывайте popover с помощью `SButton` по умолчанию или с `variant="tertiary"`, подпись которой говорит, что внутри.

Полное руководство см. в [рекомендациях Shopify для `<s-popover>`](https://shopify.dev/docs/api/app-home/latest/web-components/overlays/popover#best-practices) (на английском).
