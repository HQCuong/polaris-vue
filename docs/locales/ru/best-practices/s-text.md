- **Выбирайте семантический `type`.** Выбирайте `"strong"` для ключевых слов или фраз, `"address"` для почтового адреса или адреса электронной почты и `"redundant"` для текста, который даёт контекст пользователям программ чтения с экрана, когда тот же контент уже есть на экране. Правильный тип позволяет вспомогательным технологиям передать смысл текста.
- **Выделяйте умеренно.** Применяйте `type="strong"` к ключевым словам или числам внутри предложения, а не к целым предложениям; избыток выделения теряет эффект и затрудняет просмотр текста.
- **Используйте tone для статуса внутри текста.** Tone вроде `"critical"`, `"success"` или `"caution"` привлекают внимание к статусу, но сочетайте их с понятной формулировкой, а не поручайте цвету передавать смысл.
- **Не приглушайте важное.** `color="subdued"` подходит для временных меток и метаданных, но избегайте его для критичной информации, которую продавец должен прочитать.

```vue
<SParagraph>
  Order shipped to <SText type="address">150 Elgin St, Ottawa</SText>.
  <SText type="strong">Payment pending.</SText>
</SParagraph>
```

Полное руководство см. в [рекомендациях Shopify для `<s-text>`](https://shopify.dev/docs/api/app-home/latest/web-components/typography-and-content/text#best-practices) (на английском).
