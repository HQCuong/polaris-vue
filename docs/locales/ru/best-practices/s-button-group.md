- **Держите связанные действия вместе.** Группируйте призывы к действию, относящиеся к одной задаче, чтобы продавцы видели варианты и то, как они связаны.
- **Сохраняйте визуальную иерархию.** Используйте `variant="primary"` для кнопки основного действия и `variant="secondary"` или `variant="tertiary"` для вспомогательных, чтобы направлять внимание.
- **Не добавляйте слишком много кнопок.** Длинный ряд вариантов перегружает продавцов и затрудняет выбор.
- **Используйте сегментированную группу для переключателей.** Для тесно связанных вариантов, например переключения представлений или фильтров, задайте `gap="none"`, чтобы объединить кнопки в один сегментированный элемент управления.
- **Выделяйте деструктивные действия.** Размещайте их обдуманно и задавайте им `tone="critical"`, чтобы их было труднее вызвать случайно.

```vue
<SButtonGroup gap="none">
  <SButton>List</SButton>
  <SButton>Grid</SButton>
</SButtonGroup>
```

Полное руководство см. в [рекомендациях Shopify для `<s-button-group>`](https://shopify.dev/docs/api/app-home/latest/web-components/actions/button-group#best-practices) (на английском).
