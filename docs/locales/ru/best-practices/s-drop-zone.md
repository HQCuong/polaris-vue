- **Указывайте ограничения на файлы через `accept`.** Задайте чёткие ограничения на типы файлов, которые принимает зона перетаскивания.
- **Обрабатывайте `droprejected` с полезным сообщением.** Когда файл не проходит проверку, слушайте это событие и сообщайте продавцам, что пошло не так.
- **Рассмотрите `disabled` на время обработки.** Отключение зоны перетаскивания во время загрузки не даёт продавцам добавлять новые файлы, пока она идёт.

```vue
<SDropZone label="Product images" accept="image/*" />
```

Полное руководство см. в [рекомендациях Shopify для `<s-drop-zone>`](https://shopify.dev/docs/api/app-home/latest/web-components/forms/drop-zone#best-practices) (на английском).
