- **Начинайте с разумной даты.** Предзаполните `value`, чтобы продавцы могли быстрее сделать выбор.
- **Предлагайте быстрые варианты для частых выборов.** Пресеты вроде «Today», «Last 7 days» или «This month» избавляют продавцов от пролистывания календаря.
- **Используйте `type="range"` для начальной и конечной дат.** Выбор диапазона подходит для отчётов, аналитики и других фильтров по периоду времени.
- **Блокируйте неподходящие даты.** Используйте `allow` и `disallow`, чтобы продавцы не могли выбрать даты, недопустимые для вашего сценария.
- **Оставляйте место вокруг календаря.** Дайте ему достаточно пространства, чтобы он не мешал экранным клавиатурам и другим интерактивным элементам.
- **Продумайте даты, удалённые от текущей.** Листать по месяцам становится утомительно за пределами нескольких лет, поэтому для дат вне окна примерно в 5–10 лет предлагайте пресеты или позвольте продавцам вводить год напрямую.

```vue
<SDatePicker type="range" />
```

Полное руководство см. в [рекомендациях Shopify для `<s-date-picker>`](https://shopify.dev/docs/api/app-home/latest/web-components/forms/date-picker#best-practices) (на английском).
