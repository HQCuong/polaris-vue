- **मौजूदा color से शुरू करें।** जब merchants किसी मौजूदा color को edit करें, तो `value` को उसी पर सेट करें, ताकि वे भटकें नहीं और देख सकें कि वे किस color से बदलाव कर रहे हैं।
- **Color को संदर्भ में preview करें।** जहाँ संभव हो, picker के पास चुने गए color को उस चीज़ पर लागू करके दिखाएँ जिस पर उसका असर पड़ता है, जैसे कोई button।
- **सटीक values के लिए इसे `SColorField` के साथ इस्तेमाल करें।** Picker देखकर चुनने के लिए अच्छा है, जबकि color field merchants को सटीक hex value टाइप करने देता है।

सभी सुझावों के लिए [`<s-color-picker>` के लिए Shopify की best practices](https://shopify.dev/docs/api/app-home/latest/web-components/forms/color-picker#best-practices) (अंग्रेज़ी में) देखें।
