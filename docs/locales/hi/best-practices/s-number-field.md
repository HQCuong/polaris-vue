- **इसे केवल संख्यात्मक values तक सीमित रखें।** मात्रा, माप या प्रतिशत जैसी चीज़ों के लिए इसका उपयोग करें। अगर किसी value में अक्षर या चिह्न हो सकते हैं, जैसे product code या फ़ोन नंबर, तो इसके बजाय `STextField` का उपयोग करें।
- **इकाई दिखाएँ।** संख्या क्या मापती है यह बताने के लिए `prefix` या `suffix` का उपयोग करें, ताकि merchants को यह अनुमान न लगाना पड़े कि वे डॉलर, किलोग्राम या प्रतिशत टाइप कर रहे हैं।
- **अपने business rules से मेल खाती सीमाएँ तय करें।** ऐसे `min` और `max` values दें जो दर्शाएँ कि वास्तव में क्या अनुमत है, ताकि form सबमिट करने से पहले ही merchants सही entries की ओर बढ़ें।
- **Errors की जाँच करें और उन्हें समझाएँ।** हर संख्यात्मक entry की जाँच करें, और जब कोई विफल हो, तो सामान्य संदेश दिखाने के बजाय `error` से ठीक-ठीक बताएँ कि क्या गलत है और उसे कैसे ठीक करें।

```vue
<SNumberField label="Discount" suffix="%" :min="0" :max="100" />
```
