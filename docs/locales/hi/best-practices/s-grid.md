- **छोटी स्क्रीन के लिए योजना बनाएँ।** जो grid desktop पर काम करता है वह mobile पर बिखर सकता है। एक ही layout तय करने के बजाय सोचें कि कम चौड़ाई पर इसे कैसे reflow होना या फिर से व्यवस्थित होना चाहिए।
- **एक जैसी spacing इस्तेमाल करें।** Items के बीच समान gaps layout को एक स्थिर लय देते हैं और उसे स्कैन करना आसान बनाते हैं, इसलिए एक ही grid में spacing के अलग-अलग तरीके न मिलाएँ।
- **उस content का ध्यान रखें जो फ़िट नहीं होता।** Cells के आयाम तय होते हैं लेकिन content की लंबाई बदलती रहती है। पहले से तय करें कि बहुत लंबा या चौड़ा content wrap होगा, truncate होगा या scroll होगा।
- **जब सरल component काफ़ी हो तो वही इस्तेमाल करें।** `SGrid` शक्तिशाली है लेकिन जटिलता बढ़ाता है, इसलिए जाँच लें कि क्या कोई सरल layout component काम कर देगा, और grid को उन मामलों के लिए रखें जिन्हें इसकी क्षमताओं की ज़रूरत हो।

सभी सुझावों के लिए [`<s-grid>` के लिए Shopify की best practices](https://shopify.dev/docs/api/app-home/latest/web-components/layout-and-structure/grid#best-practices) (अंग्रेज़ी में) देखें।
