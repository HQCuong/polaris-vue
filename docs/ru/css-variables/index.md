# CSS-переменные Polaris (design tokens) {#css-variables}

Веб-компоненты Polaris оформляют себя сами, но в вашем приложении обычно есть и собственный CSS:
сетка страницы, своя карточка, легенда диаграммы, отступ между двумя компонентами. CSS-переменные
Polaris позволяют этому CSS использовать те же цвета, отступы, радиусы и шрифты, что и окружающие
компоненты, так что он соответствует дизайну админки, а не подобран наугад.

`polaris-vue-elements` поставляет их одним файлом стилей, `tokens.css`, извлечённым из
рантайма Polaris, который загружает ваше приложение.

::: warning Неофициально
Shopify не публикует список CSS-переменных для веб-компонентов Polaris. Эти имена и
значения извлечены из рантайма Shopify (`polaris-2.js`), поэтому значения следуют за
CDN, а имя может измениться или исчезнуть, если Shopify его переименует. Список проверяется ежедневно
(см. [Как список поддерживается в актуальном состоянии](#how-it-stays-up-to-date)).
:::

## Когда их использовать {#when-to-use}

- **Используйте** их для элементов, которыми владеет ваше приложение: обёрток, контейнеров
  раскладки, собственных виджетов, текста, который вы отображаете вне компонентов Polaris.
- **Не пытайтесь** с их помощью менять оформление компонентов Polaris. Каждый компонент отображается внутри
  собственного shadow root, поэтому установка `--p-color-bg-fill-brand` на вашей странице не перекрасит
  `<SButton>`. Вместо этого используйте props компонента (`tone`, `variant`, `padding`, …).
- **Сначала используйте компоненты раскладки.** `<SStack>`, `<SGrid>` и `<SBox>` уже принимают
  значения отступов, внутренних отступов и границ Polaris как props. Обращайтесь к CSS-переменным, когда
  этого недостаточно.

## Установка {#install}

Подключите файл стилей один раз, например в `main.ts`. Он нужен, даже если ваше приложение работает
внутри админки Shopify ([почему](#need-tokens-in-admin)):

```ts
import 'polaris-vue-elements/tokens.css'
```

Затем используйте переменные в любом CSS:

```vue
<template>
  <div class="summary">
    <SText type="strong">Orders today</SText>
    <SText>42</SText>
  </div>
</template>

<style scoped>
.summary {
  display: flex;
  justify-content: space-between;
  gap: var(--p-space-300);
  padding: var(--p-space-400);
  border: var(--p-border-width-025) solid var(--p-color-border);
  border-radius: var(--p-border-radius-300);
  background: var(--p-color-bg-surface);
  box-shadow: var(--p-shadow-100);
}
</style>
```

Сами имена и значения также доступны в виде JSON, для инструментов или CSS-in-JS:

```ts
import tokens from 'polaris-vue-elements/tokens.json'

tokens.tokens['--p-space-400'] // '1rem'
```

## Темы {#themes}

У рантайма два вида. Магазин с прежним дизайном админки получает базовые значения (блок
`:root` в `tokens.css`). Магазин с новым дизайном админки и любая страница вне админки
Shopify получают тему `admin-next`: когда отображается первый компонент Polaris, рантайм
добавляет в `<html>` класс `p-partial-theme-admin-next`, а `tokens.css` переопределяет
отличающиеся значения под этим же классом. Ваш CSS следует теме, выбранной рантаймом, без
дополнительных усилий. На странице [Все переменные](/ru/css-variables/reference) переключайтесь между **Base** и **admin-next**, чтобы увидеть любой из наборов значений;
наполовину закрашенная точка отмечает переменные, значение которых различается между двумя темами.

Значения, которые рантайм применяет только при дополнительных условиях (широкогамутные цвета P3, мобильные
размеры шрифта, режим высокой контрастности, поддержка `corner-shape`), не включены; в `tokens.css`
находится значение по умолчанию для каждой из них.

## Как список поддерживается в актуальном состоянии {#how-it-stays-up-to-date}

Задание по расписанию каждый день читает `polaris-2.js` из CDN Shopify, извлекает переменные
и открывает pull request, если что-то было добавлено, удалено или изменено. Каждый релиз
`polaris-vue-elements` поставляется со списком на момент этого релиза.

## FAQ {#faq}

### Есть ли у веб-компонентов Polaris CSS-переменные? {#do-polaris-web-components-have-css-variables}

Да. Рантайм Polaris (`polaris-2.js`) определяет около 700 пользовательских свойств `--p-*` на
`:root` и использует их внутри своих компонентов. Shopify их не документирует,
а имена в рантайме содержат хеш сборки. `tokens.css` даёт вам те же значения под
стабильными именами.

### Моё приложение работает внутри админки Shopify. Нужен ли мне всё равно `tokens.css`? {#need-tokens-in-admin}

Да. Рантайм определяет переменные только под именами с хешем, например
`--p-color-bg-surface-6e076`, и никогда под `--p-color-bg-surface`, поэтому без `tokens.css`
`var(--p-color-bg-surface)` ни во что не разрешается. Хеш меняется с каждой сборкой Shopify,
так что использовать имена с хешем тоже нельзя. Собственный CSS админки не доходит до вашего приложения,
потому что встроенное приложение работает в iframe.

### Можно ли менять оформление компонента Polaris с помощью этих переменных? {#can-i-restyle-a-polaris-component-with-these-variables}

Нет. Каждый компонент отображается внутри собственного shadow root и читает собственные
переменные рантайма с хешем, поэтому установка `--p-color-bg-fill-brand` на вашей странице не меняет `<SButton>`.
Используйте props компонента, такие как `tone` и `variant`. Переменные предназначены для ваших собственных
элементов вокруг компонентов.

### Почему имена переменных в DevTools заканчиваются хешем вроде `-6e076`? {#why-do-the-variable-names-in-devtools-end-in-a-hash-like-6e076}

Рантайм добавляет к каждому имени суффикс, зависящий от сборки (`--p-color-bg-surface-6e076`), и
суффикс меняется от сборки к сборке. Не копируйте эти имена в свой CSS:
`tokens.css` удаляет суффикс, поэтому `var(--p-color-bg-surface)` продолжает работать после того, как Shopify
выпустит новую сборку.

### Чем это отличается от `@shopify/polaris-tokens`? {#how-is-this-different-from-shopify-polaris-tokens}

`@shopify/polaris-tokens` — пакет токенов для Polaris React. Этот список берётся из
самого рантайма веб-компонентов, поэтому в нём есть токены, которые компоненты действительно используют, включая
значения нового дизайна админки (`admin-next`). Большинство имён общие; различия см. в
[Миграция с `@shopify/polaris-tokens`](/ru/css-variables/migration#migrating-from-polaris-tokens).

### Поддерживают ли переменные тёмный режим? {#do-the-variables-support-dark-mode}

Не как тему страницы. У рантайма есть тёмный набор значений (`admin-next-dark`), но он применяется
только к частям внутри некоторых компонентов, а к странице — никогда, поэтому в `tokens.css` нет
тёмной темы. Значения находятся в `tokens.json` под `themes["admin-next-dark"]`, если вы захотите
собрать её.
