# Миграция с `@shopify/polaris-tokens` {#migrating-from-polaris-tokens}

`@shopify/polaris-tokens` — пакет токенов Polaris React. Веб-компоненты Polaris
его не используют: рантайм определяет собственные переменные, и большинство имён совпадает. Если
CSS вашего приложения пришёл из приложения на Polaris React, сверьте его с этими списками. Имя, которое есть только
в устаревшем пакете, не имеет значения в приложении на веб-компонентах, поэтому CSS, который его использует, получит
запасное значение `var()`, которое вы указали, или ничего.
