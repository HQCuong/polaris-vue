- **Plan for smaller screens.** A grid that works on desktop can fall apart on mobile. Decide how it should reflow or rearrange at narrower widths rather than fixing one layout.
- **Use one consistent spacing.** Even gaps between items give the layout a steady rhythm and make it easier to scan, so avoid mixing spacing approaches inside a single grid.
- **Account for content that doesn't fit.** Cells have set dimensions but content lengths vary. Decide up front whether overly long or wide content should wrap, truncate or scroll.
- **Use a simpler component when it's enough.** `SGrid` is powerful but adds complexity, so check whether a simpler layout component does the job and keep the grid for cases that need what it offers.

See [Shopify's best practices for `<s-grid>`](https://shopify.dev/docs/api/app-home/latest/web-components/layout-and-structure/grid#best-practices) for the full guidance.
