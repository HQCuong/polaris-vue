- **Start from the current color.** When merchants edit an existing color, set `value` to it so they keep their bearings and can see what they're changing from.
- **Preview the color in context.** Where you can, show the chosen color applied to what it affects, such as a button, next to the picker.
- **Pair it with `SColorField` for exact values.** The picker is good for choosing visually, while a color field lets merchants type a precise hex value.

See [Shopify's best practices for `<s-color-picker>`](https://shopify.dev/docs/api/app-home/latest/web-components/forms/color-picker#best-practices) for the full guidance.
