- **Keep it for secondary content.** A popover stays hidden until merchants open it, so put less important information and actions there, not anything they need to see right away.
- **Group related actions.** The actions inside a popover should belong together.
- **Open it from a clearly labeled button.** Trigger the popover with a default or `variant="tertiary"` `SButton` whose label says what's inside.

See [Shopify's best practices for `<s-popover>`](https://shopify.dev/docs/api/app-home/latest/web-components/overlays/popover#best-practices) for the full guidance.
