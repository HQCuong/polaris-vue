- **`size="small-200"` for the tightest spaces.** Reach for it only where room is very limited.
- **`size="small"` for small spaces.** Use it when the thumbnail has to fit in a compact area.
- **`size="base"` by default.** Start here unless the layout calls for something else.
- **`size="large"` when the image is the focus.** Use it when the thumbnail is the main point of attention.
