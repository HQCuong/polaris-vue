- **Give every major section a heading.** Headings form an outline of the interface that helps merchants find their way and see how content is organized.
- **Let the component pick the heading level.** It assigns the HTML level (h2, h3, h4) from how deeply it's nested, so screen readers get a correct document structure without you setting levels by hand.
- **Be specific.** Say what the section covers, for example "Product details" or "Customer details" rather than just "Details".
- **Clamp lines only when you must.** `lineClamp` can tame long headings in tight spaces like cards, but cutting a heading short can hide information merchants need.
- **Style similar headings the same way.** Headings for the same kind of content, such as every card in a list, should look alike.

See [Shopify's best practices for `<s-heading>`](https://shopify.dev/docs/api/app-home/latest/web-components/typography-and-content/heading#best-practices) for the full guidance.
