- **Use it when order doesn't matter.** An unordered list presents related items, such as features, options or benefits, with no sequence or ranking. When the sequence matters, use `SOrderedList` instead.
- **Keep items parallel.** Give every item the same grammatical structure so the list is easy to scan. Mixing writing styles in one list makes it harder to read.
- **Write short items.** Lists work best when each item is brief. If items grow long or complex, consider breaking the content into separate sections.
- **Limit nesting.** Nested lists can organize hierarchical content, but they get hard to follow quickly. If you need more than two levels, the content may not suit a list.

See [Shopify's best practices for `<s-unordered-list>`](https://shopify.dev/docs/api/app-home/latest/web-components/layout-and-structure/unordered-list#best-practices) for the full guidance.
