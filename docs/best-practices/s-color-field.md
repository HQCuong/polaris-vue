- **Name what the color is for.** Use a `label` like "Button background color" or "Heading text color" instead of a generic "Color".
- **Show the current color when editing.** Set `value` to the existing color so merchants can see what they're changing from.

```vue
<SColorField label="Button background color" value="#1a1a1a" />
```

See [Shopify's best practices for `<s-color-field>`](https://shopify.dev/docs/api/app-home/latest/web-components/forms/color-field#best-practices) for the full guidance.
