# Politique de sécurité

> Cette traduction peut être en retard sur la version anglaise. En cas de divergence, la [version anglaise](../../SECURITY.md) fait foi.

## Versions prises en charge

Seule la dernière version de `polaris-vue-elements` reçoit des correctifs.

## Signaler une vulnérabilité

Merci de ne pas ouvrir d'issue publique. Signalez-la en privé via
[le signalement privé de vulnérabilités de GitHub](https://github.com/HQCuong/polaris-vue/security/advisories/new),
avec une description, la version concernée et les étapes pour la reproduire.

Vous devriez recevoir une réponse sous une semaine. Une fois le correctif publié, l'avis de sécurité est publié
en vous créditant, sauf si vous préférez rester anonyme.

Les vulnérabilités du runtime Polaris lui-même (`cdn.shopify.com/shopifycloud/polaris-*.js`)
relèvent de Shopify ; signalez-les via le [programme de bug bounty de Shopify](https://hackerone.com/shopify).
