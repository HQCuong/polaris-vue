# セキュリティポリシー

> この翻訳は英語版より更新が遅れている場合があります。内容に相違がある場合は、[英語版](../../SECURITY.md)が正式なものです。

## サポート対象のバージョン

修正が提供されるのは、`polaris-vue-elements` の最新リリースのみです。

## 脆弱性の報告

公開の issue は作成しないでください。[GitHub の非公開の脆弱性報告機能](https://github.com/HQCuong/polaris-vue/security/advisories/new)から、説明、影響を受けるバージョン、再現手順を添えて非公開で報告してください。

1 週間以内に返信します。修正がリリースされると、匿名を希望されない限り、あなたのクレジットを記載したアドバイザリーが公開されます。

Polaris の runtime 自体（`cdn.shopify.com/shopifycloud/polaris-*.js`）の脆弱性は Shopify の管轄です。[Shopify のバグバウンティプログラム](https://hackerone.com/shopify)から報告してください。
