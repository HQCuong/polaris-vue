# Политика безопасности

> Этот перевод может отставать от английской версии. При расхождениях приоритет имеет [английская версия](../../SECURITY.md).

## Поддерживаемые версии

Исправления получает только последний релиз `polaris-vue-elements`.

## Сообщение об уязвимости

Пожалуйста, не открывайте публичный issue. Сообщите о ней приватно через
[приватную систему сообщений об уязвимостях GitHub](https://github.com/HQCuong/polaris-vue/security/advisories/new),
указав описание, затронутую версию и шаги для воспроизведения.

Ответ вы должны получить в течение недели. После выхода исправления уведомление безопасности публикуется
с указанием вашего авторства, если только вы не предпочтёте остаться анонимным.

Уязвимости в самом runtime Polaris (`cdn.shopify.com/shopifycloud/polaris-*.js`)
относятся к Shopify; сообщайте о них через [программу bug bounty Shopify](https://hackerone.com/shopify).
