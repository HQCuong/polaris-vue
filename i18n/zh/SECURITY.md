# 安全策略

> 本译文可能落后于英文版。如有出入，以[英文版](../../SECURITY.md)为准。

## 支持的版本

只有 `polaris-vue-elements` 的最新版本会获得修复。

## 报告漏洞

请不要开公开 issue。请通过
[GitHub 的私密漏洞报告功能](https://github.com/HQCuong/polaris-vue/security/advisories/new)
私下报告，并附上问题描述、受影响的版本和复现步骤。

你应会在一周内收到回复。修复发布后，安全公告（advisory）会随之公开并致谢你的贡献，除非你希望
保持匿名。

Polaris runtime 本身（`cdn.shopify.com/shopifycloud/polaris-*.js`）的漏洞归 Shopify 负责；
请通过 [Shopify 的漏洞赏金计划](https://hackerone.com/shopify)报告。
