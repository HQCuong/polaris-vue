# सुरक्षा नीति

> यह अनुवाद अंग्रेज़ी संस्करण से पीछे हो सकता है। किसी भी अंतर की स्थिति में [अंग्रेज़ी संस्करण](../../SECURITY.md) ही मान्य है।

## समर्थित versions

केवल `polaris-vue-elements` की नवीनतम release को ही fixes मिलते हैं।

## Vulnerability की रिपोर्ट करना

कृपया कोई public issue न खोलें। इसकी रिपोर्ट निजी रूप से
[GitHub की private vulnerability reporting](https://github.com/HQCuong/polaris-vue/security/advisories/new)
के ज़रिए करें, जिसमें विवरण, प्रभावित version और reproduce करने के चरण शामिल हों।

आपको एक सप्ताह के भीतर जवाब मिल जाना चाहिए। Fix release होने के बाद advisory आपको श्रेय देते हुए
publish की जाती है, जब तक कि आप गुमनाम रहना पसंद न करें।

Polaris runtime की अपनी vulnerabilities (`cdn.shopify.com/shopifycloud/polaris-*.js`)
Shopify के दायरे में आती हैं; उनकी रिपोर्ट [Shopify के bug bounty program](https://hackerone.com/shopify) के ज़रिए करें।
