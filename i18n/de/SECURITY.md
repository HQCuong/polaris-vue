# Sicherheitsrichtlinie

> Diese Übersetzung kann hinter der englischen Fassung zurückliegen. Bei Abweichungen ist die [englische Fassung](../../SECURITY.md) maßgeblich.

## Unterstützte Versionen

Nur das neueste Release von `polaris-vue-elements` erhält Fehlerbehebungen.

## Eine Sicherheitslücke melden

Bitte kein öffentliches Issue öffnen. Die Meldung stattdessen vertraulich über
[GitHubs private Meldung von Sicherheitslücken](https://github.com/HQCuong/polaris-vue/security/advisories/new)
einreichen, mit einer Beschreibung, der betroffenen Version und Schritten zur Reproduktion.

Eine Antwort sollte innerhalb einer Woche erfolgen. Sobald eine Korrektur veröffentlicht ist, wird das Advisory
mit Nennung der meldenden Person veröffentlicht, sofern keine Anonymität gewünscht ist.

Sicherheitslücken in der Polaris-Runtime selbst (`cdn.shopify.com/shopifycloud/polaris-*.js`)
fallen in die Verantwortung von Shopify; diese bitte über das [Bug-Bounty-Programm von Shopify](https://hackerone.com/shopify) melden.
